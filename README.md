# EcoHome AI

A beginner-friendly static sustainability website built with HTML, CSS and JavaScript.

## Files
- index.html — website structure
- styles.css — responsive design
- script.js — calculator, local points, action buttons and demo AI assistant

## Run in GitHub Codespaces
Open the repository in Codespaces. For a simple static site, you can preview `index.html` using a local static server or an available preview extension.

## Publish
GitHub Pages can publish HTML/CSS/JavaScript directly from a GitHub repository.

## Important
The "AI Eco Assistant" in this competition version is a rule-based demo. It does not call a paid AI API. If you later add a real AI API, never put a private API key directly in frontend JavaScript.
